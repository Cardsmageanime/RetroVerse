# RetroVerse — Original Artwork Only Policy

**Status:** adopted October 25, 2026 for RetroVerse Systems Edition, Phases 1–5.

## Owner direction
The user shared an external ArtStation reference (https://www.artstation.com/artwork/kDAvAn), then explicitly requested removing images associated with it and using **original works** for RetroVerse.

- The ArtStation page is **reference material only**, **not a project asset**, license grant, or approved artwork source.
- Do **not** copy, scrape, download, embed, trace, recolor or redistribute that project's images, character designs, renders, layouts or logos.
- Do **not** assume matching project names mean the works are owned by RetroVerse.
- Do not use near-replicas or an external artist's distinctive characters or trade dress.
- Existing repository images must be audited for source, rights and attribution. If an asset is identified as coming from the external reference or derived without permission, remove it from current project usage and Git tracking (and review repository history/caches separately where necessary). **Do not delete unrelated original art on speculation.**

## New RetroVerse visual identity
- Original artwork, UI assets, palettes, iconography, environments, startup screens, lobby graphics, themes and backgrounds.
- Develop a distinct RetroVerse look: stylized retro-futurist interface, accessible contrast, consistent navigation, adaptable resolution, optional original theme packs.
- AI-generated imagery is optional only if clearly authorized by the owner and checked for recognizable copying.
- Keep source/design files and document creator, permission/license, asset purpose, and import commit for every shipped visual resource.
- When provenance is unknown, quarantine the asset from release/build usage until it is verified or replaced.
- Avoid hotlinking ArtStation or third-party art in themes and UI; use bundled original assets or authorized third-party components only.

## Audit status
GitHub code search for `artstation`, `kDAvAn`, and `Retroverse Toon` returned no indexed text matches on the repository default branch at the time of this review. **This does not inspect all binary images, all branches, or Git history and cannot prove that no related art exists.** No specific infringing or associated image was identified, so no repository image has been deleted on guesswork.

## Acceptance conditions
- Asset manifest lists authorship/permission for every production visual.
- Automated references to prohibited external artwork are absent.
- UI and theme assets for Phases 2 and 5 are original or explicitly licensed.
- Phase 6 remains reserved and out of scope.

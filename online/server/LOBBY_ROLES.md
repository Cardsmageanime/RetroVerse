# RetroVerse Online lobby permissions — local prototype

This system is owned by **RetroVerse**, completely separate from RetroArch's netplay menu. RetroArch can later serve as one gameplay backend, but does not own public rooms, friends, host privileges or spectator access.

Protocol remains newline-delimited JSON on loopback only (`127.0.0.1:8766`). It is **not** a public Internet service: no TLS, persistent accounts, verified friendships, abuse controls, databases or authentication. The `hello` name is unverified. Do not expose this server to a LAN or the Internet.

## Room types

- `public`: listed publicly; players may join; spectators are read-only chat recipients.
- `friends`: hidden from public room listings; joining as a player or spectator requires a one-time invite capability generated by the host. This is **not yet tied to a real friends list**.
- `creator`: hidden, invite-only host-led room. Spectators are disabled in this early prototype.
- `spectator`: a **role/view**, not a separate game host. This models the future Spectator Lobby screen. Spectators cannot send chat in this prototype.

Example message flow, each JSON object sent as one line:

```json
{"action":"hello","name":"Host"}
{"action":"create","name":"Friends Night","kind":"friends"}
{"action":"invite"}
```

Send the returned `room` ID and one-time `invite` token to your intended second participant securely. From their connection:

```json
{"action":"hello","name":"Guest"}
{"action":"join","room":"ROOM_ID_HERE","invite":"INVITE_HERE","role":"player"}
```

Use `"role":"spectator"` for a public or invited friends-room spectator. The `list` action returns only public rooms and rooms the current connection already joined. If a host disconnects or leaves, their room is destroyed and members are detached.

## Testing and scope

Run `python -m unittest discover -s online/server -p 'test_*.py' -v` or use the **Check Online and ARM UI Foundations** GitHub Actions workflow.

All invitations, membership and chat exist only in memory. They do not persist across restarts. No actual game networking, account login, authenticated friendships, cross-device session negotiation or spectator video is implemented yet. Do not treat CI passing as proof of Internet multiplayer.
